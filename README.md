# Python CI Pipeline – GitHub Actions

This repository was created as part of the Datacom Virtual Experience Program on Forage.

As part of the task, I implemented a basic CI pipeline using GitHub Actions to understand how automated workflows are triggered and executed. The workflow runs on push to the main branch and performs predefined steps in a Linux environment.

Through this project, I practiced:
- Creating and managing a GitHub repository
- Cloning and working with Git via the terminal
- Writing a simple GitHub Actions workflow using YAML
- Automating a basic CI process on code push

## Tech Used
- Git
- GitHub
- GitHub Actions
- YAML
- Python

This was an introductory-level CI setup that helped me build a clearer understanding of version control and workflow automation. I plan to continue building more advanced CI/CD implementations as I progress.
