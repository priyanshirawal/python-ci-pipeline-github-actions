# python-ci-pipeline-github-actions
As part of the Datacom virtual training program, I implemented a basic CI pipeline using GitHub Actions.  This project demonstrates repository management, version control using Git, and workflow automation using YAML. The pipeline is triggered on code push and executes predefined steps in a Linux environment.

This repository was created as part of the Datacom Virtual Experience Program.

In this task, I practiced:
- Creating and managing a GitHub repository
- Cloning a repository using Git
- Writing a basic GitHub Actions workflow using YAML
- Automating a simple CI process triggered on push to the main branch

## Tech Used
- Git
- GitHub
- GitHub Actions
- YAML
- Python

## What This Project Demonstrates
Basic understanding of version control and CI workflow automation.
